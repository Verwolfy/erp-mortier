# Benchmark de conception — Sofiane ERP

**Date :** 2026-11-08  
**Statut au 2026-11-08 :** audit de référence complété : archives Frappe, ERPNext, NocoBase 3 et Odoo 20.0 vérifiées en lecture seule ; aucune modification du code distant ni de Supabase.  
**Cible :** conserver Python 3.12 + Streamlit + Supabase/PostgreSQL ; renforcer les services et RPC existants.  
**Dépôt examiné :** `Verwolfy/erp-mortier`, `main` (`2a3dacaa62b45a0c667f3609ff474fbbbbfd19af`).

## Périmètre et provenance

Les quatre archives **Frappe** (`frappe-develop.zip`), **ERPNext** (`erpnext-develop.zip`), **NocoBase 3** (`nocobase-3-develop.zip`) et **Odoo** (`odoo-20.0.zip`) ont été inspectées en lecture seule le 2026-11-08. Les observations ci-dessous distinguent les éléments vérifiés dans les archives des adaptations proposées. Aucun code tiers n'est copié. Chaque adaptation est une proposition de conception indépendante, à confirmer par la lecture des services, des migrations et des tests réels de Sofiane ERP.
